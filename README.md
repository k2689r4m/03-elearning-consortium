## 프로젝트명
대학 이러닝 운영 통계 및 분석 시스템

## 수행 시기
2021년

## 프로젝트 소개
대학의 이러닝 강좌 운영 데이터를 통합 관리하고, 강좌 및 수강생의 학습 현황과 교육 운영 실적을 통계 형태로 조회할 수 있도록 구축한 관리·분석 시스템.

강좌 수, 수강생 수, 출결, 학습 진도, 시험, 과제, 토론, 퀴즈, 수료 및 만족도 등의 데이터를 연도·학기·대학·강좌 단위로 관리하고 이를 대시보드와 그래프를 통해 시각화한다.

## 주요 기술
- PHP / Laravel 8
- JavaScript
- D3.js
- Vue.js
- Blade Template
- MySQL 계열 관계형 DB
- Laravel Excel
- HTML / SCSS / Bootstrap

## 주요 기능

### 이러닝 운영 데이터 관리
- 대학 및 강좌별 운영 데이터 관리
- 연도/학기별 통계 관리
- 강좌 수 및 수강생 수 관리
- 출석률·지각률·결석률 관리
- 학습 진도율 및 수료율 관리
- 시험 응시율 관리
- 과제 수행률 관리
- 토론 참여율 관리
- 퀴즈 수행률 관리
- 학습 참여도 관리
- 성적 관련 통계 관리
- 만족도 및 교육 운영 평가 데이터 관리

### 통계 대시보드
- 대학 및 강좌별 운영 현황 시각화
- 전체 평균과 개별 대학/강좌 데이터 비교
- 출결·진도·수료 등 주요 지표 그래프 제공
- 시험·과제·토론·퀴즈 등 학습 참여 지표 시각화
- 만족도 및 평가 결과 시각화
- 연도/학기별 데이터 조회

### Excel 데이터 처리
- Excel 기반 운영 데이터 처리
- 입력된 Excel 데이터를 서비스에서 사용하는 데이터 구조로 변환
- 가공된 데이터를 통계 및 대시보드에서 사용할 수 있도록 처리
- 관리 데이터 Excel 출력 기능 제공

## 담당 업무
**D3.js 데이터 시각화 / Excel 데이터 가공 담당**

### D3.js 데이터 시각화
- D3.js를 이용한 커스텀 통계 그래프 구현
- 강좌 및 수강생 현황 데이터 시각화
- 출결·진도·수료 등 학습 관련 지표 시각화
- 시험·과제·토론·퀴즈 참여 데이터 그래프 구현
- 만족도 및 평가 결과 그래프 구현
- 서버에서 전달받은 데이터를 그래프에 맞는 형태로 변환하여 표현

### Excel 데이터 가공
- 제공받은 Excel 데이터를 시스템에서 사용할 수 있는 데이터 형태로 변환
- Excel 컬럼 및 데이터를 서비스 데이터 구조에 맞게 매핑
- 통계 및 대시보드에서 사용할 수 있도록 데이터 정제 및 가공

## 프로젝트 내 역할
프로젝트 전체 개발보다는 데이터 처리 및 시각화 영역을 중심으로 참여하였다.

외부에서 제공되는 Excel 기반 교육 운영 데이터를 서비스에서 활용할 수 있는 형태로 가공하고, D3.js를 이용하여 주요 교육 운영 지표를 커스텀 그래프로 시각화하는 기능을 담당하였다.
